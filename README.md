# Світло 5.1 — LG webOS 3.0 TV + Живі сповіщення (Тернопільобленерго)

Готовий проєкт для телевізора **LG LH590U (webOS 3.0)** без руту:
1. **Великий TV-додаток** (хоститься на Render) — показує поточний статус світла для черги **5.1**, зворотний відлік, шкалу на сьогодні/завтра і підсвітку змін.
2. **Фоновий нотифікатор для ПК** (`tv-notifier/`) — по домашньому Wi-Fi надсилає рідні спливаючі сповіщення LG поверх телеканалів / YouTube:
   - за **30 хвилин** до відключення;
   - за **10 хвилин** до відключення;
   - одразу, коли **графік змінився**.

---

## Крок 1. Деплой на Render
1. Завантажте цю папку в новий репозиторій на GitHub.
2. На [render.com](https://render.com/) створіть **Web Service**, підключіть репозиторій:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
3. Після деплою відкрийте отриману адресу (наприклад `https://ternopil-svitlo.onrender.com`) у браузері — має одразу показати графік для черги **5.1**.

---

## Крок 2. Встановлення додатку на LG TV (без руту)
1. Впишіть вашу адресу Render у файл `webos-app/index.html` (рядок `var RENDER_URL = ...`).
2. На телевізорі зайдіть у **LG Content Store** → встановіть безкоштовний офіційний додаток **Developer Mode**.
3. Відкрийте **Developer Mode**, увійдіть в LG-акаунт, увімкніть **Dev Mode Status: ON** (телевізор перезавантажиться) і увімкніть **Key Server: ON**. Запам'ятайте **IP-адресу** і **Passphrase**.
4. На ПК завантажте зручну програму **webOS Dev Manager** (з GitHub `webosbrew/dev-manager-desktop`).
5. Підключіться до телевізора по IP + Passphrase → зберіть `.ipk` з папки `webos-app` (або встановіть папку через `ares-package webos-app && ares-install ...`).
6. Додаток **«Світло 5.1»** з'явиться в нижньому меню телевізора (перетягніть його на перше місце).

> *Примітка:* У LG Developer Mode є таймер (~50 год), який можна продовжувати натисканням однієї кнопки в **webOS Dev Manager** або автоматично.

---

## Крок 3. Живі спливаючі сповіщення поверх відео (з ПК, без руту)
1. На телевізорі перевірте, що увімкнено: *Налаштування → Мережа → LG Connect Apps → Увімк.*
2. Впишіть локальну IP-адресу телевізора у файл `tv-notifier/config.json` (`"tvIp": "192.168.x.x"`).
3. У папці проєкту виконайте:
   ```bash
   npm install
   node tv-notifier/notifier.js --test
   ```
4. На екрані телевізора з'явиться запит на підключення — натисніть **«Прийняти»** пультом. Одразу після цього вискочить тестове сповіщення!
5. Для постійної роботи запускайте:
   ```bash
   npm run notifier
   ```
   *(Можна додати в автозавантаження Windows, щоб працювало у фоні, поки увімкнений ПК).*
